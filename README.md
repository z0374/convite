# 🎉 Convite de Aniversário Personalizado

Um template de convite de aniversário digital, interativo e fácil de personalizar. Ideal para envio via WhatsApp ou hospedagem em páginas como o GitHub Pages.

## 🚀 Funcionalidades

- **Responsivo:** Funciona bem em celulares e computadores.
- **Interativo:** Botões para confirmar presença ou ver localização.
- **Personalizável:** Fácil alteração de textos, datas e imagens.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
